  If user_vs_expert ~ 0: GENERIC endorsement sensitivity

INTERPRETATION GUIDE
======================================================================

If USER-SPECIFIC:
  The model specifically defers to perceived user preferences.
  This suggests instruction tuning created a 'please the user' bias.

If GENERIC:
  The model responds equally to any endorsement, regardless of source.
  This suggests a general compliance/agreement tendency.

Key insight: Compare 'User' vs 'Note' too - if even 'Note' (non-agentive)
  produces similar effects, the model may just be text-completion biased.
